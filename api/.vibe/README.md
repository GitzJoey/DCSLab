# Vibe Coding Instructions - DCSLab API

This directory contains system instructions for AI coding assistants working on the Laravel API.
The project is based on laravel 13 (or latest) styles

- Read RULES_ARCHITECTURE.md for the global application architecture/layering rules (Controllers, Form Requests, Actions, API Resources). These apply to all code in the project.
- Read 01_INSTALLATION.md for installing the Laravel including the required pre-requisite.
- Read 02_MIGRATIONS.md for creating migration files
- Read 03_MODELS.md for creating model files
- Read 04_FACTORIES.md for creating factory files
