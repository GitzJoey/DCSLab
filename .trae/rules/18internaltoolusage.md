# Aturan Penggunaan Tool Internal Trae

- Fokus utama: hasil akurat dan minim salah konteks.
- Gunakan tool internal Trae untuk search, glob, grep, read, dan patch/edit.
- Jangan buat file/script sementara seperti `check.php`, `scan.py`, `replace.php`, `tmp.js`, atau `temp.txt` hanya untuk mencari, memindai, menghitung pola, cek urutan method, atau replace.
- Jangan buat script sementara untuk mengatasi quoting command.
- File baru hanya boleh dibuat jika memang bagian dari source code proyek atau diminta eksplisit oleh user.
